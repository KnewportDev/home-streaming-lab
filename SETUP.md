# Put the kit on GitHub

This package has two READMEs: one for the streaming lab and one for the account profile.

## Streaming lab repository

Use `pc-to-tv-streaming-lab` as the repository name. Upload the package contents with `README.md` at the repository root. Include the hidden `.gitignore` file and `results/.gitkeep`.

The `profile/` folder holds a separate copy for the account profile. It can stay in the lab repository too; the next section explains where to copy it.

The root README references `assets/knewport-header.svg`. Keep that relative path intact.

## Account profile

Set the display name to **Knewport 🚬**. The display name can differ from the GitHub username.

GitHub shows a profile README from a public repository named exactly after the account's username. Copy the contents of `profile/` into that repository:

```text
README.md
assets/
  knewport-header.svg
```

Don't upload `profile/` as a surrounding folder. Its README needs to be at the repository root.

Suggested bio:

Windows, networking, cybersecurity, and a home lab built around gaming.

Once the lab repository exists, link the profile's project title to its verified URL and pin the repository. No account name or repository URL is assumed in this kit.

## Keep it clean

The header uses charcoal, muted sage, readable type, and a small cigarette drawing. Keep the native GitHub typography and left-aligned sections below it. Skip the stats widgets and badge walls.

Add a real setup photo and a screenshot from the first working stream when they're available. Update the status and hardware details as the build progresses. Keep credentials, pairing codes, private logs, personal notifications, and identifying network details out of screenshots and commits.
